# Kenick Color Palette

This document defines the official color palette extracted from the onboarding and signup mockups. These colors should be used consistently across the entire mobile application.

## Core Colors

| Role | Color Value (Hex) | Description |
| :--- | :--- | :--- |
| **Primary** | `#EAB308` (0xFFEAB308) | The signature gold/yellow color used for primary buttons, highlights, and active states. |
| **White** | `#FFFFFF` (0xFFFFFFFF) | Pure white, used for surfaces, cards, and text in dark mode. |
| **Black** | `#000000` (0xFF000000) | Pure black, used for dark mode gradients and absolute black elements. |

## Light Mode Colors

| Role | Color Value (Hex) | Description |
| :--- | :--- | :--- |
| **Background** | `#EBE5E4` (0xFFEBE5E4) | The primary light background color used across the app (e.g., Sign In, Sign Up, Profile Setup). |
| **Cream/Gradient**| `#FFFBEB` (0xFFFFFBEB) | The light cream color used for gradients (e.g., Onboarding screen). |
| **Text** | `#111827` (0xFF111827) | The primary dark gray/black color for text in light mode. |
| **Surface** | `#FFFFFF` (0xFFFFFFFF) | Used for text fields, cards, and bottom sheets in light mode. |
| **Borders** | `#E5E7EB` (0xFFE5E7EB) | Light gray used for input borders and dividers. |
| **Hint Text** | `#9CA3AF` (0xFF9CA3AF) | Gray used for input placeholders and secondary text. |

## Dark Mode Colors

| Role | Color Value (Hex) | Description |
| :--- | :--- | :--- |
| **Dark Background**| `#08060D` (0xFF08060D) | The primary very dark background color used for the main scaffold in dark mode. |
| **Dark Surface** | `#1E1E1E` (0xFF1E1E1E) | The slightly lighter dark color used for text fields, cards, and bottom sheets in dark mode. |
| **Dark Text** | `#F9FAFB` (0xFFF9FAFB) | The near-white color for text in dark mode. |
| **Dark Borders** | `#424242` (Colors.grey.shade800) | Dark gray used for borders and dividers in dark mode. |
