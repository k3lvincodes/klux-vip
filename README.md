# Klux VIP

Flutter app for Klux VIP.

## Get started

1. Install Flutter SDK

   ```bash
   flutter pub get
   ```

2. Run the app

   ```bash
   flutter run
   ```

Run the app from your terminal with `flutter run`.

Edit the Flutter code under `lib/`.
